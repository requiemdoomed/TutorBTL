# TutorBTL

A responsive website introducing online and on-site tutoring
with Swayam Shakya.

## Features

- Tutoring services and tutor introduction
- School subjects for Grades 1–10
- Physics, English, and Computer Science for 10+2
- Phone and email contact links
- Mobile-friendly design

## Built With

HTML and CSS.

## Run

Download the project and open `TutorBTL.html` in your browser.
No installation required.

## Note

This is an informational website. Booking and payments
are not included.
